# MONDAY — LifeOps AI

MONDAY is a TanStack Start full-stack application combining:

- Supabase authentication, row-level security, and application storage
- A Google OAuth connector for Gmail and Google Calendar
- Hugging Face chat completions for planning and prioritisation
- A React/Tailwind workspace for inbox, calendar, weekly planning, and profile management

## Local setup

```bash
copy .env.example .env.local
npm install
npm run dev
```

On macOS/Linux, use `cp .env.example .env.local`.

Before deployment:

```bash
npm run format
npm run check
```

Commit the `package-lock.json` generated by `npm install`. Do not commit `.env.local`.

The browser and server use the same Supabase URL and publishable-key values under different variable names:

```text
VITE_SUPABASE_URL == SUPABASE_URL
VITE_SUPABASE_PUBLISHABLE_KEY == SUPABASE_PUBLISHABLE_KEY
```

Only `VITE_` variables are exposed to browser code. `SUPABASE_SECRET_KEY`, Google secrets, and the Hugging Face token must remain server-only.
